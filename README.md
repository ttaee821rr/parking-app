# 🚗 내 차 어디?

주차한 위치를 저장해 두고, 나중에 지도와 길찾기로 다시 찾아가는 웹앱입니다.

**👉 바로 사용하기: https://ttaee821rr.github.io/parking-app/**

## 주요 기능

- 📍 버튼 한 번으로 현재 위치를 주차 위치로 저장
- 🗺️ 지도에 내 차 위치 표시
- 🧭 카카오맵 길찾기로 바로 연결
- 🗑️ 출차 후 기록 삭제
- 💾 새로고침하거나 앱을 다시 열어도 저장된 위치 유지
- 📝 층·구역 메모 (자동 저장)
- 💰 요금표 기반 예상 주차 요금 실시간 계산

## 개발 예정

- [ ] 주차 시간 (주차 후 경과 시간 표시)
- [ ] 주차장 메모 (층, 구역 등)
- [x] 예상 주차 요금 계산
- [ ] 기둥 번호 사진 · 층 빠른 입력
- [ ] 디자인 개선
- [ ] 주차장 메모 (층, 구역 등) → - [x] 주차장 메모 (층, 구역 등)

## 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 화면 | HTML, CSS, JavaScript (프레임워크 없음) |
| 위치 | Geolocation API |
| 저장 | localStorage |
| 지도 | Leaflet 1.9.4 + OpenStreetMap |
| 길찾기 | 카카오맵 URL 링크 |
| 배포 | GitHub Pages |

## 개인정보와 보안

- 주차 위치는 **사용자 기기의 브라우저에만 저장**되며 서버로 전송되지 않습니다.
- 외부 라이브러리(Leaflet)는 **SRI(Subresource Integrity)**로 무결성을 검사합니다. 변조된 파일은 실행되지 않습니다.
- API 키나 비밀 정보가 필요 없는 구조입니다.

## 파일 구조

```
parking-app/
├── index.html   # 화면 구조
├── style.css    # 디자인
└── app.js       # 기능 (위치 저장, 지도, 길찾기)
```

## 내 컴퓨터에서 실행하기

프로젝트 폴더에서 아래 명령어를 실행한 뒤, 브라우저에서 `http://127.0.0.1:5500`에 접속합니다.

```bash
python3 -m http.server 5500 --bind 127.0.0.1
```

> 위치 기능은 HTTPS 또는 localhost에서만 동작하므로, `index.html`을 더블클릭해서 열면 위치를 가져오지 못할 수 있습니다.
